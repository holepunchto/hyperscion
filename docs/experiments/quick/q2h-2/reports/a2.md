Nothing is lost; retry when the hub or a teammate's watch is online`. Meanwhile `hs doctor` said `verdict ok: a holder is online`, and `hs land` once said `hs: stalled: ... Run hs fetch`. `hs fetch` then hung for about 2 minutes and fixed nothing. As a result my approved P3 (the CONTRACTS.md Plan shape) never landed. I had to `hs restore /CONTRACTS.md` and land the code alone.

If it can't, `doctor` should report it as not ok and name the core. A `hs land --except <path>` or an automatic "land the unprotected files, propose the protected ones" option would also have saved time.
